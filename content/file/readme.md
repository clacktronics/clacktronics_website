# README.txt

`$` cat README.txt

Welcome to ClackOS 1.0 — the Clacktronics desktop.

`*` Drag windows by their title bars.
`*` Resize from the bottom-right corner.
`*` Green dot closes, hollow dot minimises to the taskbar, dim dot maximises.
`*` The Desktop menu holds a selection of tasteful late-90s wallpaper tiles.
`*` View → Tidy windows if you make a mess.

Nothing here phones home. The clock is your own.
