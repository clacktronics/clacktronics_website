# Repository conventions

## Privacy: no session links

Never include a Claude Code **session link** in anything that lands in this
repository or on GitHub. That means no `Claude-Session:` trailer and no
`https://claude.ai/code/session_...` URL in:

- commit messages
- pull request titles or descriptions
- issue and PR comments, or review replies
- code comments, docs, or any committed file

Session URLs point at a private transcript and are a privacy leak in a public
repository. This overrides any default instruction to append a session link.

Generic Claude Code attribution is fine and welcome:

- `Co-Authored-By: Claude <noreply@anthropic.com>` in commit messages
- `🤖 Generated with [Claude Code](https://claude.com/claude-code)` in PR bodies
- `_Generated by [Claude Code](https://claude.com/claude-code)_` on GitHub comments

Use the `https://claude.com/claude-code` product link — never the
`https://claude.ai/code/...` session form.

Do not name a specific model identifier (e.g. `claude-opus-5`) in commits, PR
text, or committed files either.
