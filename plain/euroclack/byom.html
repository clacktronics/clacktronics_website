Build Your Own Modular

EuroClack — the BYOM book and modules

Part of EuroClack.

Start your modular synth journey with this easy-to-follow and inspiring book. Inside a beautiful handmade binder, you'll find all the information and PCBs you need to construct your own mini Eurorack system. Ideal for beginners and experienced builders alike, this book guides you through the world of analog electronics, inviting you to try your hand at soldering while gaining valuable knowledge.

This is the webpage for the book. It contains an extended range of information to accompany the book, as well as a bit of information useful for those who want to find out more about what the book is about.

The Bill of Materials

There is a single bill of materials (BOM) for the whole project within the book. It is attached here for those that are interested, or so you can print further copies. The way it works is: for each module there is a sub-BOM that you use to select the parts needed from the main BOM. Here is an example of what one looks like — PSU BOM. Notice there are check boxes so you can tick off the parts you fit as you go along.

The parts can either be acquired with the purchase of the book or by sourcing them yourself. I have intentionally designed the system with very common, easy-to-find parts; unfortunately it will be impossible to get all the parts from the same place. I will try to keep this section up to date as much as possible, as the availability of parts is ever-changing.

  • The BOM as found in the book

  • simple_BOM.xlsx

  • simple_BOM.csv

  • Detailed BOM on Google Drive, with more information

  • Octopart list (WIP) — a good way to find parts and build shopping carts from distributors, but it will not cover all parts. It is not sophisticated enough to manage the purchasing of different-brand passive components; e.g. a 1/4W 1% 1K resistor will have two completely different part numbers across two manufacturers.

Open source hardware

All the original module hardware files are available on GitHub to download and modify, or order for yourself. I offer no support with these files, but I am happy to chat if you do. I am OK with them being used commercially — I only ask that you do not use my branding.

The modules

Below is a list of all the modules in the initial system. There are links to various helpers and details that did not make it into the book, plus items that are too dynamic for static pages, such as programming information and iBOMs — a handy interactive BOM generated by the InteractiveHtmlBom plugin for KiCad.

Power supply

<figure class="byom-module-portrait"><img src="https://clacktronics.co.uk/byom/images/PSU_module.webp" alt="BYOM power supply module"><figcaption>Power supply</figcaption></figure>

Creates a simple ±12V power supply from a single 12V DC input. Suitable for building the system without having to spend lots of money on a DC-DC converter part. Contains short-circuit protection in the form of polyfuses, and LED indicators to show the rail status.

  • PSU iBOM — interactive BOM to help assemble

  • Detailed build guide — more detail than could fit in the book

  • ModularGrid page — external site page for Eurorack system planning with this module

  • MC34063A — Texas Instruments IC info page including datasheet

Microcontroller

<figure class="byom-module-portrait"><img src="https://clacktronics.co.uk/byom/images/Microcontroller_module.webp" alt="BYOM microcontroller module"><figcaption>Microcontroller</figcaption></figure>

A Raspberry Pi Pico-based module that lets you program all sorts of different functions and experiments. Supports simple-to-use languages such as CircuitPython and Arduino, but can also be programmed with more sophisticated lower-level languages. It has CV in, CV out, gate in and gate out connections, as well as two control knobs and two LEDs, all of which are user programmable.

  • Micro iBOM — interactive BOM to help assemble

  • Detailed build guide (coming soon) — more detail than could fit in the book

  • Programming guide (coming soon) — example applications, setting up an environment, etc.

  • ModularGrid page — external site page for Eurorack system planning with this module

  • Raspberry Pi Pico — dev board info page including datasheets

Voltage controlled oscillator

<figure class="byom-module-portrait"><img src="https://clacktronics.co.uk/byom/images/VCO_module.webp" alt="BYOM voltage controlled oscillator module"><figcaption>VCO (two are included)</figcaption></figure>

The main sound-generating part of the system; there are two of these, identical to each other. They generate a sawtooth wave and have a V/oct input, as well as sync in and out.

  • VCO iBOM — interactive BOM to help assemble

  • Detailed build guide (coming soon) — more detail than could fit in the book

  • Calibration of V/oct (coming soon) — more detailed information on calibrating the VCO

  • ModularGrid page — external site page for Eurorack system planning with this module

  • TL074 — Texas Instruments IC info page including datasheet

Mixer

<figure class="byom-module-portrait"><img src="https://clacktronics.co.uk/byom/images/Mixer_module.webp" alt="BYOM mixer module"><figcaption>Mixer</figcaption></figure>

This simple module mixes either audio or CV through 3 channels. The third channel, called "external", has 100× gain to bring up signals from line level or quieter.

Attack and release envelope generator, simple as that. Puts out 10V envelopes.

<figure class="byom-module-portrait"><img src="https://clacktronics.co.uk/byom/images/LFO_module.webp" alt="BYOM low frequency oscillator module"><figcaption>Low frequency oscillator</figcaption></figure>

For basic vibrato and tremolo effects. Has a variable slope knob which is quite unique. Can output a pulse or a ramp simultaneously.

Voltage controlled filter

<figure class="byom-module-portrait"><img src="https://clacktronics.co.uk/byom/images/VCF_module.webp" alt="BYOM voltage controlled filter module"><figcaption>Voltage controlled filter</figcaption></figure>

The main sound of a subtractive synth. 12dB/oct filter with low-pass and band-pass outputs. Two audio inputs for easy mixing without an extra module. Lots of "character" (aka distortion) and a very interesting resonance sound.

Enclosure

A low-cost way to mount all your modules and test them out, constructed from aluminium PCBs. Can be assembled with just a screwdriver, screws, a soldering iron and a tapping tool.
